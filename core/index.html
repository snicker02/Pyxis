Organon

ὄργανον: the shared engine behind Brad's 3D fractal explorers.

Organon is a progressive WebGL1 raymarcher and app shell, covering rendering, scene, UI, animation, export and Mandelbulber import. Each app adds one formula module and uses Organon as a git submodule.

  • Kyma: Amazing Surf
  • Eidos: Kaleidoscopic IFS

The formula contract, submodule set-up and a template app are in the README.
