# Mandelbulber scenes

These `.fract` files come from the example collections that ship with [Mandelbulber 2](https://github.com/buddhi1980/mandelbulber2) (`deploy/share/mandelbulber2/examples/`). They are licensed **Creative Commons Attribution 4.0 (CC-BY 4.0)**: https://creativecommons.org/licenses/by/4.0/

Pyxis's Mandelbulber presets are made from them by the app's own importer (`node tools/build-scenes.mjs`). Cameras, colours and formula values are kept as the authors set them, so a preset can differ from Mandelbulber's render wherever the import notes list something Pyxis doesn't support.
